# Ozon Product Collector

Локальное расширение для Chrome и Firefox (Manifest V3), которое собирает карточки товаров
из поисковой выдачи и каталога Ozon, сохраняет их в `storage.local` и экспортирует в CSV/JSON.

Расширение не открывает карточки товаров, не покупает товары, не авторизуется и не обходит
ограничения Ozon. Оно читает только ту разметку, которая уже загружена в открытой вкладке.

## Возможности

- Автоматическое обнаружение карточек при загрузке выдачи, прокрутке (бесконечная лента),
  смене фильтров, пагинации и SPA-переходах.
- `MutationObserver` + редкий резервный таймер; обработка порциями в `requestIdleCallback`,
  без агрессивного polling.
- Дедупликация по `product_id`, а при его отсутствии — по нормализованному URL карточки.
- Раздельное хранение текущего состояния товара и истории наблюдений.
- Сессии сбора: каждый запуск имеет свой `session_id`, данные переживают перезагрузку вкладки
  и перезапуск браузера.
- Явный запуск и остановка сбора; после перезапуска браузера сбор **не возобновляется**
  автоматически (незавершённая сессия помечается `interrupted`).
- Popup со счётчиками: обнаруженные карточки, уникальные товары, ошибки извлечения,
  общее число товаров в базе; текущий URL, время начала и последнего извлечения.
- Экспорт одной выбранной сессии или всех данных: CSV товаров, CSV наблюдений, JSON.
- Защита качества: при массовом провале извлечения пакет не сохраняется, пользователь видит
  предупреждение; при низком качестве цен данные сохраняются, но помечаются предупреждением.
- Русский интерфейс, английские имена полей и заголовки CSV (удобно для анализа).

## Установка

Сначала соберите расширение (нужен Node.js 24+ и `zip`):

```bash
npm install
npm run build
```

Готовые файлы появятся в:

- `dist/chrome/` и `dist/ozon-collector-chrome.zip`
- `dist/firefox/` и `dist/ozon-collector-firefox.zip`

### Chrome / Chromium

1. Откройте `chrome://extensions/`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `dist/chrome`.
4. Закрепите расширение на панели. Для обновления после пересборки нажмите «Обновить».

ZIP-архив `dist/ozon-collector-chrome.zip` можно распаковать и загрузить тем же способом.
Для установки из ZIP без распаковки Chrome требует публикацию в магазине; локальная установка
выполняется из папки.

### Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите «Загрузить временное дополнение…».
3. Выберите файл `dist/firefox/manifest.json` (именно manifest, не ZIP).
4. Дополнение работает до перезапуска Firefox; после перезапуска загрузите его снова.

Для постоянной локальной установки в Firefox Developer Edition / Nightly можно отключить
обязательную подпись (`xpinstall.signatures.required = false` в `about:config`) и установить
подписанный или временный пакет. Обычный Firefox требует подписи Mozilla для постоянной
установки; это ограничение браузера, а не расширения.

## Использование

1. Откройте страницу поиска или каталога Ozon, например `https://www.ozon.ru/search/?text=крем`.
2. Откройте popup расширения и нажмите «Начать сбор».
3. Просматривайте выдачу обычным образом: прокручивайте, переходите по страницам, меняйте фильтры.
4. Счётчики обновляются автоматически. Предупреждение о качестве появляется, если разметка
   изменилась или карточки не удаётся разобрать.
5. Нажмите «Остановить» — расширение сохранит уже обнаруженные карточки и перестанет сканировать.
6. Выберите область экспорта: «Все данные», текущая сессия или конкретная сессия.
7. Скачайте «CSV товары», «CSV наблюдения» или «JSON».
8. «Очистить накопленные данные» удаляет товары, наблюдения и сессии без возможности отмены.

Сбор работает только на страницах `ozon.ru` с поиском/каталогом. На карточке товара,
в корзине и личном кабинете сканирование не выполняется. Перезагрузка вкладки не сбрасывает
сессию: после загрузки страницы сбор продолжается, если он был включён.

## Какие поля собираются

| Поле | Описание | Если недоступно |
| --- | --- | --- |
| `product_id` | Числовой id Ozon из URL карточки | `null`, дедупликация по URL |
| `url` | Прямая ссылка на карточку без query/hash | `null` |
| `title` | Полное видимое название | `null` |
| `price` | Основная отображаемая цена числом | `null` |
| `currency` | Валюта (`RUB`, `KZT`, …) | `null` |
| `original_price` | Зачёркнутая цена числом | `null` |
| `discount` | Явно показанная скидка, % | `null` |
| `discount_text` | Исходная надпись скидки (`-38%`, `Скидка 20%`) | `null` |
| `volume` + `volume_unit` | Объём/вес из названия (`ml`, `l`, `g`, `kg`) | `null` |
| `quantity` | Количество единиц в упаковке | `null` |
| `seller` | Продавец, если показан на карточке | `null` |
| `rating` | Рейтинг 0–5 | `null` |
| `review_count` | Число отзывов/оценок | `null` |
| `availability` | `in_stock`, `out_of_stock` или `null` | `null` |
| `collected_at` | Время обнаружения (ISO 8601, UTC) | — |
| `source_url` | URL страницы выдачи | — |

Неизвестные значения никогда не заменяются нулями, средними ценами или догадками.
Для каждого поля хранится состояние: `extracted`, `absent` (поля нет в карточке) или
`failed` (поле есть, но не распознано). Это позволяет отдельно анализировать неполные данные.

### Цены

В карточке могут одновременно отображаться несколько цен. Они сохраняются раздельно:

- `prices.main` — основная цена (`price`);
- `prices.original` — зачёркнутая цена (`original_price`);
- `prices.ozon_card` — цена с Ozon Картой;
- `prices.subscription` — цена по подписке;
- `prices.other` — прочие варианты с условиями;
- `discount` — процент скидки, если он явно показан (не вычисляется из двух цен).

У каждой цены есть `type`, `amount`, `currency`, `raw_text` и `conditions`. В CSV вынесены
отдельные колонки `ozon_card_price`, `subscription_price`, `other_prices` (JSON-массив).

## Экспорт

- **CSV товары** — одна строка на уникальный товар, актуальное состояние.
- **CSV наблюдения** — одна строка на каждое обнаружение, включая повторы и `null`.
- **JSON** — полный bundle: товары, наблюдения, сессии, статистика, `extracted_fields`,
  `missing_fields`, `failed_fields`, `fallback_fields`, `extraction_errors`, версия парсера.

CSV: UTF-8 с BOM, CRLF, корректное экранирование кавычек/запятых/переносов строк.
Имена файлов содержат дату: `ozon-products-2026-11-11.csv`, `ozon-session-data-2026-11-11.json`.
Подробное описание колонок и JSON — в [docs/CSV_JSON.md](docs/CSV_JSON.md).

## Приватность и разрешения

- Разрешения: `storage`, `unlimitedStorage`.
- `host_permissions`: только `https://*.ozon.ru/*` и `https://ozon.ru/*`. Доступ к URL вкладок
  ограничен этими хостами; отдельное разрешение `tabs` не запрашивается.
- Данные не покидают браузер: нет серверов, аналитики, телеметрии и удалённого кода.
- Не читаются cookies, токены, пароли и поля ввода; DOM карточек не изменяется.
- Расширение не прокручивает страницу и не имитирует действия пользователя.
- `unlimitedStorage` нужен, потому что `storage.local` имеет квоту, а история наблюдений
  для 1000+ карточек может быть объёмной.
- В манифесте Firefox указано `data_collection_permissions.required = ["none"]`:
  расширение не собирает и не передаёт данные за пределы браузера.

## Архитектура

```
src/
  adapters/browser.ts     browser/chrome API + storage adapter
  background/index.ts     сообщения, жизненный цикл сбора, badge, экспорт
  content/
    index.ts              батчинг карточек, состояние, SPA-навигация
    scanner.ts            MutationObserver, idle-обработка, повторы
    card-extractor.ts     извлечение одной карточки
    selectors.ts          все Ozon-селекторы в одном месте
    jsonld.ts             резервный источник из JSON-LD
  parser/                 чистые парсеры цен, объёма, URL, рейтинга, наличия
  storage/                репозиторий, ключи, дедупликация, экспортные выборки
  export/                 CSV/JSON, имена файлов, MIME
  popup/                  HTML/CSS/TS интерфейса
  shared/                 типы, константы, утилиты
tests/                    unit/integration тесты и 36 контрольных карточек
docs/                     архитектура, CSV/JSON, селекторы, точность, тестирование
scripts/                  сборка, иконки, отчёты, benchmark
```

Парсинг не зависит от браузерных API, поэтому тестируется в Node.js с `jsdom`.
Фоновый скрипт — единственный писатель в хранилище: content script отправляет пакеты карточек,
background последовательно применяет их и повторяет запись при ошибке.

Подробное описание компонентов, потока данных, схемы хранения, дедупликации, quality guard
и принятых решений — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

### Хранение

- `p:<hash>` — товар (актуальное состояние);
- `pidx:<n>` — чанки индекса товаров;
- `session:<id>` — сессия;
- `obs:<session>:<n>` — чанки наблюдений;
- `session_index`, `state`, `meta` — служебные данные.

Ключ дедупликации — `id:<product_id>` или `url:<нормализованный URL>`, для хранения —
стабильный 64-битный FNV-1a хеш с защитой от коллизий. Индекс и наблюдения пишутся чанками,
поэтому одна запись не переписывает всю базу.

## Сборка и проверки

```bash
npm install
npm run typecheck      # tsc --noEmit
npm test               # unit/integration тесты (Node test runner)
npm run test:coverage  # покрытие
npm run accuracy       # отчёт по 36 контрольным карточкам
npm run bench          # нагрузочный тест (по умолчанию 5000 товаров)
npm run build          # dist/chrome, dist/firefox и ZIP-архивы
npm run verify         # typecheck + tests + build
```

Переменная `BENCH_PRODUCTS` задаёт размер выборки: `BENCH_PRODUCTS=1000 npm run bench`.

## Проверка на живом Ozon

Автотесты используют синтетическую разметку. Перед реальным использованием пройдите
ручную проверку (5–10 минут):

1. Соберите расширение и загрузите его в браузер.
2. Откройте поиск Ozon, запустите сбор, прокрутите 2–3 экрана.
3. Сверьте 5–10 карточек: URL, название, цена, зачёркнутая цена, продавец, рейтинг.
4. Выполните экспорт CSV и откройте его в Excel/Google Sheets — кириллица и цены должны быть
   корректны.
5. Перейдите на следующую страницу выдачи и убедитесь, что счётчик растёт.
6. Перезагрузите вкладку — сбор должен продолжиться, дубликатов в базе быть не должно.
7. Остановите сбор, перезапустите браузер — сбор не должен запуститься сам.
8. Если появилось предупреждение о качестве, пришлите HTML одной карточки: селекторы нужно
   обновить по инструкции [docs/SELECTORS.md](docs/SELECTORS.md).

Точность на синтетической выборке и ограничения методики — в [docs/ACCURACY.md](docs/ACCURACY.md).
Нагрузочные показатели — в [docs/TESTING.md](docs/TESTING.md).

В этой среде расширение дополнительно проверено в локальном Firefox (160.0): загрузка,
старт/остановка, первоначальная выдача, динамическая карточка, SPA-переход, дедупликация,
CSV/JSON и очистка — PASS. Проверка шла на тестовой странице с разметкой Ozon; живой `ozon.ru` вернул HTTP 403,
поэтому реальные селекторы всё ещё нужно сверить по чек-листу выше.

## Известные ограничения

- Собирается только то, что пользователь фактически загрузил в DOM; расширение не утверждает,
  что просмотрело всю выдачу.
- Если на карточке нет продавца, рейтинга или цены, соответствующие поля остаются `null`.
- Объём/количество извлекаются из названия; диапазоны (`100–200 мл`) и неоднозначные случаи
  дают `null` и `failed` в состоянии поля.
- Цены с Ozon Картой и подпиской зависят от региона, авторизации и настроек аккаунта.
- Разметка Ozon меняется. Селекторы централизованы, есть generic-фолбэки и защита от массового
  сохранения мусора, но при крупном редизайне потребуется обновление `src/content/selectors.ts`.
- Firefox требует подписи для постоянной установки; временное дополнение загружается заново
  после перезапуска браузера.
- Лимит одного сообщения — 100 карточек; content script сам разбивает очередь на пакеты.
- `storage.local` в Chrome и Firefox имеет разные физические лимиты и скорость записи; для
  очень больших баз (десятки тысяч товаров) может потребоваться IndexedDB.
