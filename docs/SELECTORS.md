# Обновление селекторов при изменении разметки Ozon

Ozon регулярно меняет классы и структуру выдачи. Все Ozon-специфичные селекторы собраны в
одном файле: [`src/content/selectors.ts`](../src/content/selectors.ts). Логика извлечения —
в [`src/content/card-extractor.ts`](../src/content/card-extractor.ts), она не зависит от UI
расширения и от браузерных API.

## Когда нужно обновление

Признаки:

- в popup появилось предупреждение «Низкое качество извлечения…»;
- счётчик «карточек» растёт, а «уникальных» почти не меняется;
- в CSV много пустых `url`, `title` или `price`;
- `extraction_status = failed` у большинства строк;
- цена/название извлекаются из соседней карточки (сдвиг границ карточки).

Не пытайтесь «лечить» это увеличением задержек или повторным запуском: сначала проверьте
селекторы и границы карточки.

## Как устроено извлечение

1. **Ссылка на товар** — `a[href*="/product/"]`. Ссылки на отзывы/вопросы/похожие товары
   (`/reviews/`, `/questions/` и т.п.) отбрасываются в `src/parser/url.ts`.
2. **Корень карточки** — `findCardRoot`:
   - сначала `CARD_ROOT_SELECTORS` (`.tile-root`, `[data-widget="searchResultsV2"]` и т.д.);
   - затем generic fallback: ближайший `div/article/li/section`, внутри которого 1–4 ссылки
     на товар, есть текст и цена или изображение.
3. **Название** — `TITLE_SELECTORS`, затем ссылка с наибольшим осмысленным текстом, затем
   `img[alt]`. Служебные подписи («Купить», «В корзину», проценты, продавец) отбрасываются.
4. **Цены** — все элементы внутри карточки, чей текст содержит ровно одну денежную величину.
   Учитываются:
   - зачёркивание (`s`, `del`, `strike`, `line-through`, `old-price`);
   - подписи «с Ozon Картой», «без Ozon Карты», «по подписке», «₽/мес», «₽/шт»;
   - размер/жирность шрифта и классы `price/headline` для выбора основной цены;
   - контейнер с несколькими ценами не передаёт свои подписи отдельной цене.
5. **Скидка** — только явные метки `-35%`, `Скидка 20%`, `20% скидка`; проценты в названии
   (например, «Масло 10%») скидкой не считаются.
6. **Объём/количество** — из названия, чистые парсеры в `src/parser/volume.ts`.
7. **Рейтинг/отзывы** — `RATING_SELECTORS` / `REVIEW_SELECTORS`, затем аккуратный fallback
   по тексту карточки рядом со словами «отзыв/оценка/рейтинг».
8. **Наличие** — по тексту карточки (`нет в наличии`, `осталось N`, `в наличии`).
9. **JSON-LD** — только резерв для полей, которых нет на видимой карточке. Основной источник —
   карточка.

## Что менять

### 1. Корень карточки

Если карточки склеиваются (в одной записи несколько товаров) или обрезаются:

- откройте DevTools → Elements, найдите карточку;
- посмотрите устойчивые атрибуты: `data-widget`, `data-index`, `tile-root`;
- добавьте селектор в начало `CARD_ROOT_SELECTORS` (более специфичный — выше);
- проверьте, что внутри корня 1–8 ссылок на `/product/`.

Не удаляйте старые селекторы сразу: Ozon может отдавать разные версии разметки (A/B, регион,
авторизация). Не привязывайтесь к хешированным классам вида `a1b2c3` — они меняются чаще всего.

### 2. Название

Добавьте новый селектор в `TITLE_SELECTORS` выше generic-вариантов. Требования:

- текст не должен содержать цену, «Купить», «В корзину», рейтинг, продавца;
- полное название, а не обрезанное многоточием (если Ozon обрезает визуально, берите
  `title`/`aria-label`, если они содержат полный текст);
- селектор должен работать для карточек с бейджами («Хит», «Оригинал») — бейдж не должен
  приклеиваться к названию.

### 3. Цены

Если цена не находится:

- проверьте, что символ валюты присутствует в тексте (`₽`, `руб.`, `р.`, `₸`, `Br`, `$`, `€`);
- посмотрите, не разделена ли цена на несколько элементов (целая часть и копейки). В таком
  случае лучше добавить селектор контейнера в логику `collectPriceCandidates`, а не склеивать
  текст вручную;
- убедитесь, что цена не является платежом в месяц (`₽/мес`) или за единицу (`₽/шт`).

Если основная и зачёркнутая цены перепутаны:

- проверьте фактическое зачёркивание в DevTools (Computed → `text-decoration`);
- проверьте, не является ли «старая» цена на самом деле ценой с картой/подпиской;
- не используйте эвристику «большая цена = зачёркнутая» без проверки: она ошибается на скидках
  и специальных ценах.

### 4. Продавец, рейтинг, отзывы, наличие

Добавляйте селекторы в соответствующие массивы. Помните:

- продавец не должен совпадать с названием товара или «Ozon»;
- рейтинг — число 0–5 с десятичным разделителем `,` или `.`;
- «нет отзывов» → `review_count = 0`, а не `null`;
- «осталось 2 шт» → `in_stock`, но не `quantity = 2`.

### 5. Версия

После изменения логики извлечения обновите `EXTRACTION_VERSION` в
`src/content/selectors.ts` (или `PARSER_VERSION` в `src/shared/constants.ts` для парсеров).
Версия попадает в CSV/JSON и помогает понять, какими правилами собраны данные.

## Обязательная проверка после правки

1. Добавьте/обновите контрольную карточку в `tests/fixtures/cards.ts`
   (минимум: обычная, со скидкой, с Ozon Картой, без цены, с длинным названием).
2. Запустите:

   ```bash
   npm run typecheck
   npm test
   npm run accuracy
   ```

3. Требования тестов:
   - URL и `product_id` — 100% там, где доступны;
   - название и цена — не менее 98% на контрольной выборке;
   - отсутствующие поля остаются `null`;
   - нет ложного объединения разных товаров.

4. Проверьте на живом Ozon (5–10 карточек) по инструкции из README.
5. Пересоберите `npm run build` и перезагрузите расширение.

## Защита от массовых ошибок

- Пакет из 5+ карточек **не сохраняется**, если распознано меньше 80% идентификаторов или
  меньше 60% названий. В popup появляется предупреждение, счётчик ошибок растёт.
- Если цена найдена менее чем у 50% карточек или полное извлечение менее 50%, данные
  сохраняются, но появляется предупреждение о качестве.
- Состояния `absent` и `failed` различаются: можно отличить «поля нет» от «поле есть, но
  сломалось».
- JSON-LD не маскирует сломанные селекторы: fallback фиксируется в `fallback_fields`.

## Что прислать при проблеме

Если нужна помощь с обновлением селекторов, пришлите:

- URL страницы выдачи (без личных данных);
- скриншот карточки;
- HTML одной карточки: DevTools → Elements → правый клик по корню карточки →
  Copy → Copy outerHTML;
- строку из CSV с неверными данными;
- версию расширения и браузера.

Не присылайте cookies, токены, данные аккаунта и адреса доставки — они не нужны.

## Ограничения

- Расширение не использует внутренние API Ozon, не обходит антибот-защиту и CAPTCHA.
- Если Ozon отдаёт контент только после входа в аккаунт, расширение не пытается
  авторизоваться; оно видит только доступную страницу.
- При капитальном редизайне может потребоваться не только новый селектор, но и правка
  эвристик (например, если цена и старая цена поменялись местами в DOM).
